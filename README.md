# CampusFlow

Application mobile de suivi des cours, des échéances et des tâches d'un étudiant.

TP de Programmation mobile, Master 1 MSI, année 2026-2027 (enseignant : M. Moctar Compaoré).
Auteur : **Belem Armel**, Master 1 MSI.

Le projet est construit séance par séance : de la décision de plateforme jusqu'à une application Flutter connectée à une API avec authentification.

## Organisation du dépôt

| Dossier | Contenu |
|---|---|
| `docs/` | Livrables de conception (séances 1 et 2), captures et notes |
| `campusflow_models/` | Package Dart des modèles (séance 3) |
| `app/` | Application Flutter CampusFlow (séances 4 à 7) |
| `server/` | API simulée avec json-server (séance 7) |
